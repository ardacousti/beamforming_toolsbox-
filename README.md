# Beamforming Toolbox for MATLAB

This repository provides a MATLAB toolbox for acoustic beamforming using both **Conventional Beamforming (CBF)** and **Spherical Harmonic Beamforming (SHB)**. It was developed to evaluate the influence of spherical microphone array geometries on acoustic imaging performance under ideal conditions.

The toolbox computes several objective performance metrics, including:

Mainlobe-to-source Level Difference (MLD),
Mainlobe-to-Sidelobe Ratio (MSR),
Solid Angle Ratio (SAR) based on the −3 dB mainlobe area.

To reproduce the results presented in the paper, please run the *main_code.m* script.
